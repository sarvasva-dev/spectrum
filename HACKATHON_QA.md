# Hackathon Q&A 

## 1. How is this project tailored for a Hackathon environment?
The architecture prioritizes a **working prototype** and rapid development over complex, premature optimizations.
- **SQLite3:** Avoids the overhead of provisioning, authenticating, and maintaining a separate SQL server (like PostgreSQL) during development.
- **Leafmap + Folium/Leaflet:** We utilize the Python `leafmap` library directly within the Django backend instead of deploying heavy SPA frameworks (React/Vue). The maps are generated on the server and easily served via HTML.
- **Clean Structure:** The repository was refactored into strict `backend/` and `frontend/` directories, allowing judges and developers to instantly understand the topology without searching through layered Django defaults.

## 2. How are the Maps Implemented?
The core map implementation leverages the **Leafmap Python package using the Folium/Leaflet rendering backend**.
- **Why Leafmap:** Using Leafmap allows us to construct robust geographical logic and maps natively in Python (Django) before passing the resulting HTML representation (`_repr_html_()`) securely to our frontend templates.
- **Rendering:** Django embeds the HTML generated by Leafmap directly into an iframe (`<div class="folium-map-container">`).
- **GPS Integration:** We use the native Browser Geolocation API (`navigator.geolocation`). When a user clicks "Use My Current Location", Vanilla JS fetches their GPS, accesses the Folium map generated inside the iframe, dynamically moves the marker to their location, and updates the hidden `latitude` and `longitude` fields to submit to Django.
- **Manual Selection:** When a user clicks directly on the map, our Vanilla JS intercepts the event from the Leafmap object, updates the marker's UI position, and modifies the hidden lat/lng form inputs.

## 3. How does the Hotspot detection work?
The hotspot algorithm runs efficiently on the backend in `views.py`. When rendering the admin dashboard, the system:
1. Gathers all non-resolved complaints.
2. Iterates through the list, comparing the latitude and longitude of each complaint against all others using the **Haversine formula**.
3. If multiple complaints are found within a **0.5km radius**, they are grouped into a "Hotspot".
4. Hotspots with 3+ reports trigger a recommendation for "Deploy Extra Bin", while 2+ triggers "Schedule Daily Clearance".
5. The resulting **hotspot coordinates are visualized** natively via `folium.Circle()` markers superimposed directly onto the Admin Leafmap instance.

## 4. What is the overarching design system?
The UI adheres strictly to the **Blue Light Theme** requested.
- We utilize modern UI patterns: glass-morphism hints, rounded geometries (`--radius-lg: 16px`), and soft elevation shadows.
- Distinct status colors (Amber for pending, Green for resolved) help municipal admins process information at a glance.
- All application pages are standalone HTML templates in `frontend/pages/` containing inline styles and scripts for 100% component independence and optimal rendering performance.

## 5. What was avoided intentionally?
Deployment configurations. The prompt strictly mandated `LOCAL DEVELOPMENT ONLY`. Therefore, there are no Dockerfiles, Nginx configurations, Gunicorn files, or systemd services. The focus was kept purely on creating a beautiful, functional, and logically sound Django application that boots instantly with `python manage.py runserver`.

## 6. What is the API Visualizer (`/visual/`)?
We built a dedicated dark-themed API Visualizer to demonstrate how frontend interactions translate into backend data operations. It provides a real-time, interactive environment to execute endpoints like `/api/complaints/` and view the JSON response payloads, status codes, and latency, making it an excellent technical showcase for the hackathon judges.

## 7. What is the Man of the Month feature (`/man-of-the-month/`)?
To gamify and incentivize community participation, CleanLoop includes a 'Man of the Month' (Community Contributor) feature. It dynamically queries the Django ORM to identify the citizen with the highest number of valid (non-rejected) waste reports in the current month. The backend includes sophisticated tie-breaking logic (falling back to earliest registration date) while ensuring admin/staff accounts are excluded from the competition.
