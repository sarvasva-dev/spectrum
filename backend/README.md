# 🛠️ CleanLoop Backend Module

This folder contains the complete Django backend application for the CleanLoop Smart Waste Management platform.

For a comprehensive guide on how every file functions and how modules interact together end-to-end, please read:

👉 **[BACKEND_ARCHITECTURE.md](BACKEND_ARCHITECTURE.md)**

## Quick Structure

- `manage.py` — Django CLI helper
- `smartwaste_project/` — Project Engine & Settings (`settings.py`, `urls.py`, `wsgi.py`, `asgi.py`)
- `waste_management/` — Feature Module (`models.py`, `views.py`, `ai_assistant.py`, `admin_ai_assistant.py`, `forms.py`, `tests.py`)
