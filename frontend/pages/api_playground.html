💾 SQLITE3 DATABASE SCHEMA

Live records are persisted securely in db.sqlite3 using standard Django ORM models.

Complaint Table
• complaint_id CharField (WM-YYYY-NNNN)
• issue_type CharField
• priority CharField (Auto Smart)
• status CharField (Lifecycle)
• latitude/longitude FloatField
PickupRequest Table
• pickup_id CharField (PK-YYYY-NNNN)
• waste_category CharField
• quantity CharField
• preferred_date DateField
• status CharField
UserProfile Table
• user OneToOne(User)
• clean_coins IntegerField (+50 reward)
• phone / address CharField
• is_admin_staff BooleanField
ComplaintUpdate Table
• complaint ForeignKey(Complaint)
• status CharField
• note TextField (Audit Log)
• created_at DateTimeField
📖 API ENDPOINT CATALOG
METHOD ENDPOINT PURPOSE AUTHORIZATION
GET /api/health/ Lightweight server & DB health status Public
GET /api/complaints/ Retrieve complaint records list from SQLite3 Public / User Scoped
GET /api/complaints/<id>/ Retrieve detailed complaint object Owner / Staff Only
POST /api/complaints/ Submit new waste report with smart auto-priority Authenticated / Demo
PATCH /api/complaints/<id>/ Update complaint status, priority & assign crew Staff Admin Only
DELETE /api/complaints/<id>/ Delete complaint record from database Staff Admin Only
